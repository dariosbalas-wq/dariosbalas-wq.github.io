Privacy policy

This application is a private backup tool used only by its owner. It has no other users.

What data it accesses

It uses the Google Drive scope drive.file, so it can only see, create, edit and delete the files and folders that it created itself in the owner's Google Drive. It cannot see any other files in the Drive.

How the data is used

Data is used only to store and retrieve the owner's own backup copies. Nothing is sold, shared with third parties, used for advertising, or used to train AI models.

Where the data is stored

Backup files are stored in the owner's own Google Drive. The access token is stored only in rclone's configuration file on the owner's own computer and server.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
